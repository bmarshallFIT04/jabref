4- Overeritten Bibtatex Code When Using CTRL+V
Fix: Ctrl+V now pastes clipboard content into the current edited entry without overwriting.
Overview: JabRef would overwrite the code whenever Ctrl+V was used, and now the shortcut works with the field “note” to prevent that.
Problem: The shortcut Ctrl+V would overwrite citation keys.
Solution: Used the pasteEntry to fetch from the clipboard and insert it into the “note” field, which would end up not overwriting the citation key.
